# Заметки (Android 16)

Заметки с галочками, списками-чеклистами, напоминаниями, виджетом и голосовым вводом.

## Что умеет
- Заметка: заголовок, текст, пункты с галочками, галочка «Выполнено» на всю заметку.
- Автосохранение (кнопки «Сохранить» нет), пустые заметки не сохраняются.
- Напоминание: дата → время. Уведомление с кнопкой «Выполнено». Будильники восстанавливаются после перезагрузки.
- Виджет: список заметок, галочку можно ставить прямо с рабочего стола, «+» — новая заметка.
- Микрофон в заметке — голосовой ввод (через распознавание речи Google на телефоне).
- Цвета подстраиваются под обои (Material You), тёмная тема.

## Как собрать
**Android Studio:** File → Open → папка `Notes` → дождаться синхронизации → Run.

**GitHub:** каждая отправка кода собирает APK и публикует релиз.
Свежий APK всегда здесь: https://github.com/Kriogad/notes-app/releases/latest/download/Notes.apk

## Устройство кода
| Файл | Что внутри |
|---|---|
| `Notes.kt` | Модель заметки, хранение в `notes.json` |
| `Ui.kt` | Экраны: список и редактор |
| `Reminders.kt` | Будильники, уведомления, перезапуск после перезагрузки |
| `NotesWidget.kt` | Виджет рабочего стола (Glance) |
| `MainActivity.kt` | Тема, голосовой ввод, разрешения |
