# Заметки — паспорт проекта (для ИИ-ассистента / нового разработчика)

Android-приложение «Заметки»: обычные заметки-списки с голосовым вводом, напоминаниями и виджетами; зашифрованный раздел («секретка»); общие списки и синхронизация между устройствами и браузером через Firebase. Хозяин проекта — **Kriogad** (Денис), общается по-русски.

## Стек и сборка

- Kotlin, Jetpack Compose (Material 3), Glance (виджеты), minSdk 26, targetSdk/compileSdk 36.
- Сборка: GitHub Actions `.github/workflows/build.yml` — на каждый пуш в `main`: `./gradlew assembleRelease` → артефакт + GitHub Release `v1.<run_number>` с `Notes.apk`.
- **Автообновление**: `Updater.kt` опрашивает `releases/latest` и предлагает обновление в приложении. `versionCode = GITHUB_RUN_NUMBER`, поэтому каждая сборка ставится поверх.
- Подпись: постоянный ключ `app/notes.jks` (закоммичен, пароль `notes123`) — без него обновление поверх невозможно.
- `google-services.json` закоммичен; `build.gradle.kts` подключает Firebase-плагин только если файл есть.
- Локальной проверки сборки нет — проверка = зелёный workflow на GitHub.

## Модель данных и JSON-ключи

`Note`: `id,title,text,items,done,remind,rep,snd,vol,da,due,pos,rd,cat,del,urg,att,s,updated`
(`pos` — порядок перетаскивания Double; `del` — deletedAt корзины; `urg` — срочная; `s` — серия повторяющейся; `rd` — показание счётчика; `cat` — категория; `att` — вложения).

`CheckItem`: `t,c,i,r,rep,snd,vol,urg` (текст, checked, id, remindAt, repeat, sound, volume, urgent).

**При добавлении поля**: обновить `toJson`/`fromJson` в `Notes.kt` (ключи опциональные — старые версии не сломаются) и при надобности `docs/sync.html`.

## Синхронизация (`Sync.kt` + `docs/sync.html`)

- Firebase RTDB: `sync/<код>/notes|trash|vault/<id> = {j: <json>, u: <updated>}`, слушатели ChildEventListener; побеждает больший `updated`.
- Секретка шифруется на клиенте до отправки; в браузере расшифровывается тем же ключом (Web Crypto).
- Фото — base64 в базе (Storage требует платный тариф — не использовать).
- `docs/` опубликован на GitHub Pages: `sync.html` — полная веб-версия (заметки, секретка, корзина, браузерные напоминания); `index.html` — веб-версия общих списков.

## Принятые решения (не ломать)

- Сортировка: невыполненные → срочные (`urgent`) → `pos`. Срочные — `colorScheme.error` (и в виджетах, и в sync.html).
- «Срочно» голосом: `DateParser.stripUrgent` вырезает слово и ставит флаг; применяется во всех точках голосового ввода.
- Секретка: ручное сохранение (кнопка «Сохранить» + диалог о несохранённом), пункты за «•••» с глазом, запрет скриншотов и скрытие из «недавних».
- Drag-and-drop пунктов: `pointerInput(Unit)` + try/finally сброс — жест не должен обрываться при смене позиций (был баг наложения строк).
- Корзина 30 дней (`Notes.TRASH_DAYS`); удаление из корзины — окончательное.
- Поле ввода в общих списках — `imePadding` (клавиатура не должна перекрывать).
- Комментарии в коде — по-русски, сообщения коммитов — по-русски.

## Workflow с ИИ-ассистентом

Правки → `git commit` + `git push` → ждать ~3 мин → проверить `GET /repos/Kriogad/notes-app/actions/runs?per_page=1` до `completed/success` → только потом сообщать пользователю «готово, обновление прилетит само».
